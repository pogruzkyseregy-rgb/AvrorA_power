# AvrorA_power — карточка для RuStore

**Название:** AvrorA_power

**Краткое описание (до 80 символов):**
Монитор батареи в стиле HUD: заряд, ток, температура, графики и уведомления.

**Полное описание:**

AvrorA_power показывает состояние батареи и памяти телефона в виде HUD-интерфейса.

- Заряд, напряжение, ток, температура, источник питания (сеть, USB, беспроводная)
- Время до полной зарядки и прогноз времени до разрядки
- Здоровье и технология батареи, использование ОЗУ и памяти
- Графики заряда, напряжения, тока, температуры, ОЗУ и памяти за всё время записи
- Анимация при подключении зарядки
- Уведомления: подключение и отключение зарядки, низкий заряд, полная зарядка
- Очистка кэша приложений и поиск больших файлов с подтверждением перед удалением
- Уровень сигнала сотовой связи и график его истории
- Определение режима «белых списков» в мобильной сети
- Настройки: 5 цветовых схем, 5 стилей панелей, 3 вида кольца заряда

Все данные хранятся только на вашем телефоне. Приложение делает короткие запросы к нескольким общедоступным сайтам раз в минуту, только чтобы определить доступность интернета. Личные данные при этом не передаются.

## Объяснение разрешений (для модерации)

| Разрешение | Зачем |
|---|---|
| Уведомления (POST_NOTIFICATIONS) | Оповещения о подключении зарядки, низком заряде и полной зарядке |
| Фоновая служба (FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNC) | Запись истории заряда каждые 30 секунд, даже когда приложение закрыто. В строке уведомлений виден постоянный значок службы |
| Поверх других приложений (SYSTEM_ALERT_WINDOW) | Анимация подключения зарядки поверх открытого приложения. Разрешение можно отключить в настройках, тогда анимация будет только внутри приложения |
| Экран блокировки / полноэкранные уведомления (USE_FULL_SCREEN_INTENT) | Показ анимации подключения, когда экран выключен или заблокирован |
| Доступ ко всем файлам (MANAGE_EXTERNAL_STORAGE) | Поиск больших файлов и очистка кэша в выбранных папках. Системные папки (Android) не трогаются. Удаление только после подтверждения пользователя |
| Игнорирование оптимизации батареи (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) | Чтобы система не останавливала запись истории в фоне. Пользователь выбирает это сам в настройках |
| Интернет (INTERNET), состояние сети (ACCESS_NETWORK_STATE) | Раз в минуту короткие запросы к нескольким сайтам, чтобы определить режим белых списков в мобильной сети. Данные пользователя не передаются |
| Состояние телефона (READ_PHONE_STATE) | Чтение уровня сигнала сотовой связи для графика и значка сети |
